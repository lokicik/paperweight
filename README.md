# Paperweight

See what makes a PDF heavy, then make a smaller, verified copy. Open a document, explore its size map, inspect the images and pages behind the numbers, and compress it. Split, combine and reorder pages, and turn presentations into PDFs. Everything runs on your computer.

**Status:** early Windows desktop prototype, built with Tauri 2 and a bundled Python/PyMuPDF engine.

## Features

- A space map of images, page drawing instructions, fonts and other parts. Large parts keep their true share; small ones are enlarged further down, so scrolling reveals every part.
- Image and page previews, with links between components and referencing pages.
- Page inventory with exclusive and shared resource sizes.
- Search, sorting, pagination and JSON report export.
- Analysis progress and cancellation.
- Compression to a separate copy: Lossless, High, Balanced or Compact, or a size limit. Text stays selectable PDF text; on heavy pages the artwork underneath is redrawn as one image, or large pictures are re-encoded at their own resolution.
- Optional cleanup of editing data from design apps, page thumbnails, attached files and document metadata, shown only when a PDF has them.
- Pages you choose are never redrawn.
- When a size limit can't be met, the copy can also be split into parts that each fit, saved as a ZIP.
- Organize pages: drag to reorder, turn, delete, add blank pages or pages from other PDFs, with undo. Saving makes a new PDF; every unturned page is checked against its source.
- Several PDFs at once, each with its own checked copy, saved one by one or together.
- Combine several PDFs into one, in the order you set. Each file becomes a top-level bookmark over its own bookmarks; links inside each file keep working, and every page is checked against its file.
- Split a PDF every N pages, at page ranges, at bookmarks down to a chosen level, or into parts under a size. Each part keeps the bookmarks and links inside it; parts are saved one by one or as a ZIP.
- Open PowerPoint presentations (.pptx, .ppt, .ppsx and more) as PDFs, converted by Microsoft PowerPoint or LibreOffice when one is installed. Save the PDF, make it smaller, split it or combine it with others.
- Opens PDFs passed at launch: double-click, Open with, or a file dropped on the app icon.
- Page preview before compressing: see any page, or the heaviest ones, at every quality next to the original, with zoom.
- Every copy is checked against the original on all pages (text, links, bookmarks, page boxes) before it is offered. Redrawn pages can be compared side by side.
- No account, external upload or telemetry. Original PDFs are opened read-only.

## Development on Windows

Prerequisites: Python 3.12, Node.js with pnpm, Rust, the Microsoft C++ build tools and WebView2. See the [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/).

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e . -r requirements-build.txt
pnpm install --frozen-lockfile
.\.venv\Scripts\python scripts/build_sidecar.py
pnpm dev
```

The sidecar bundles Python, PyMuPDF and the web assets. Desktop users do not need to install Python. Rebuild the sidecar after changing Python or web files.

For a faster browser development loop:

```powershell
.\start.ps1
# Open http://127.0.0.1:8766
```

An optional local sample can be supplied explicitly; no personal paths are built in:

```powershell
.\start.ps1 --sample C:\path\to\your-document.pdf
```

## Build a Windows installer

```powershell
.\.venv\Scripts\python scripts/build_sidecar.py
pnpm build
```

The installer is generated in `src-tauri/target/release/bundle/nsis/`. Development builds are unsigned. macOS and Linux packaging have not been validated.

## Test

```powershell
.\.venv\Scripts\python -m unittest discover -s tests -v
pnpm check:frontend
# After building the engine executable:
.\.venv\Scripts\python scripts/smoke_sidecar.py
```

Fixtures are generated by the tests. The executable check covers analysis, shared-resource accounting, image/page previews, cancellation and managed shutdown. Books, rendered book pages, local outputs and executables are excluded from Git.

## How the desktop app works

Tauri starts the bundled engine on a dynamically assigned loopback port and opens its interface in WebView2. The web interface receives no Tauri shell or filesystem permissions. When the desktop parent exits, the engine stops its jobs and removes the temporary working copies created during that session. An abnormal termination can leave temporary files in the operating system's temp directory.

The local browser mode uses the same engine. It is for local use, not an internet-facing server.

## Reading the sizes

Each active encoded stream is counted once. The structural remainder completes the exact file total. Shared resources can appear in multiple page totals, so page costs are not additive. Stored size does not predict how many bytes compression would save.
