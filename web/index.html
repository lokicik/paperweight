How sizes are counted

Each part of the file is counted once, so the blocks add up to the file’s size on disk. A picture used on several pages still counts once.

A page’s size includes everything it uses, so shared parts appear under every page that uses them. That is why page sizes don’t add up to the file size.

These are the sizes stored today, not a prediction of savings. Savings are measured on the finished copy.
